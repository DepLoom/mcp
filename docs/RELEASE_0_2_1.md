# MCP 0.2.1

This release adds the explicit-goal planning, host-registered isolated candidate
verification, separately authorized final apply and current/historical checkpoint
routes. Health planning remains PLANNING_ONLY. Imported JSON or agent prose cannot
grant execution authority. Read the [support matrix](GOAL_EXECUTION_SUPPORT.md)
before using these routes.

It includes read-only owner-qualified npm-workspace inventory/proposals,
on-demand hash-pinned official migration references and syntax-only local usage
observations. Workspace inventory is not joint solving or workspace execution.
Unknown semantic applicability, stale evidence and unsupported cases stay unknown.

A bounded four-reader Core integrity loop still reads and hashes fresh bytes on
every invocation. Local component measurements are not whole-migration speedup.
The shipped Skill contract is 2.0.2; automatic client injection is not proven by
an installation receipt.

## Benchmark registry configuration

Public benchmark controls default to the original npm registry and frozen seed
hash. Operator-specific registry addresses are not embedded in this repository.
A private registry profile requires explicit `D1_NPM_REGISTRY` in the local
operator environment; missing configuration or URLs containing credentials,
queries, fragments or whitespace are rejected. Source-hash controls are unchanged:
a different registry/fixture is a separate pinned workload, never a public
control relabelled as PASS. Historical local private runs are not public evidence.

This release does not claim autonomous agent repair, universally faster migration,
security closure outside the agreed profile, pnpm/Yarn/workspace execution or a
commercial advantage. Existing distribution terms are unchanged.
