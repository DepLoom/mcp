# Connecting OpenCode to DepLoom MCP

The canonical, maintained instructions live in
[`integrations/opencode/README.md`](../../integrations/opencode/README.md).
They cover both parts of the setup — registering the `deploom` MCP server
(`get_upgrade_plan`) **and** installing the `deploom-upgrade` skill via
`scripts/install_skill.py`. Copy the config into your own OpenCode
configuration; this repository never modifies global OpenCode configuration.
